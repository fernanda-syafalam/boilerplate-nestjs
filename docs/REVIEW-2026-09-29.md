# Boilerplate review — 2026-09-29

Scope: all of `src/`, `test/`, `Dockerfile`, CI and `k8s/`, reviewed for correctness,
security and design principles (DRY, KISS, YAGNI, SRP/DIP, comments, consistency).
Branch `chore/prune-comments` addresses every finding below; the Status column
records the outcome.

## A. Bugs and security

| # | Finding | Status |
|---|---|---|
| A1 | Public signup accepted `role: 'admin'` (privilege escalation) | Fixed — `role` removed from input; signup always creates `customer` |
| A2 | `GET /v1/users` and `/:id` open to any authenticated user | Fixed — list admin-only; `:id` admin-or-self, 404 otherwise |
| A3 | BullMQ `jobId` contained `:` → `Custom Id cannot contain :` at enqueue | Fixed — `order-confirm-<id>`, regression test added |
| A4 | OTel SIGTERM handler called `process.exit` before Nest drained | Fixed — `registerGracefulShutdown`: close Nest → flush OTel → exit |
| A5 | HTTP pods also consumed the email queue | Fixed — `EmailWorkerModule` imported by the worker only |
| A6 | `JwtAuthGuard` ran before `ThrottlerGuard` (401s never throttled) | Fixed — throttler first |
| A7 | `trustProxy: true` unconditionally (spoofable `X-Forwarded-For`) | Fixed — `TRUST_PROXY_HOPS`, default 0, ConfigMap sets 1 |
| A8 | Non-uuid `:id` / malformed cursor → 500 | Fixed — zod param/query DTOs → 400 |
| A9 | Check-then-insert race; soft-deleted email → 500 | Fixed — `onConflictDoNothing` → 409 |
| A10 | CORS wildcard "enforced" only in a comment | Fixed — schema rejects `*` |
| A11 | No production cookie refinements | Fixed — prod requires `COOKIE_SECURE`; `SameSite=none` requires secure |
| A12 | Invalid dummy argon2 hash (possible timing oracle) | Fixed — real dummy hash computed at startup |
| A13 | Client `x-request-id` trusted as-is | Fixed — charset + length validated |
| A14 | Refresh minted a token before checking the user exists | Fixed — consume → load user → mint |
| A15 | Filter skipped logging 5xx / non-Error throws; dropped `checks` | Fixed — all 5xx logged; 5xx body stripped to standard members (allowlist `checks`) |
| A16 | JWT algorithm not pinned; no issuer/audience | Fixed — HS256 pinned; `JWT_ISSUER` / `JWT_AUDIENCE` signed and verified |
| A17 | `@ZodSerializerDto` was a no-op (interceptor never registered) — `POST /v1/users` returned `passwordHash` | Fixed — `ZodSerializerInterceptor` global |

## B. Design principles

| Area | Finding | Status |
|---|---|---|
| Comments | ~28% of `src/` lines were comments; six contradicted the code | Fixed — 500 → 48 comment lines, why-only |
| DRY | Role list ×4, config type ×9, `AuthUser` mapping ×3, `JwtPayload` ×2, argon2 options ×2, `ConfigModule` setup ×2, env parsed twice, CI setup ×3 | Fixed — `userRole.enumValues`, `AppConfigService`, `toAuthUser`, one `JwtPayload`, `PasswordHasher`, `AppConfigModule`, `parseEnv()`, composite action |
| KISS | Test-only branch in throttler factory; seed with `await` in a loop; half-wrapped Redis client | Fixed — e2e override the throttler options; single `insert … onConflictDoNothing`; clients built in constructors |

| SRP/DIP | Repository threw HTTP exceptions; auth used `UsersRepository` directly; password logic split across modules; `AuthUser` in `common/decorators` | Fixed — repository returns `null`/`boolean`; `UsersModule` exports only `UsersService`; `SecurityModule`; `common/types/auth-user.ts` |
| Consistency | Nest `Logger` vs `PinoLogger`; manual query parsing; manual response stripping; `updatedAt` never updated; case-sensitive email | Fixed — `PinoLogger` everywhere; zod DTOs; serializer; `$onUpdate`; lowercase input + `0002_lowercase_emails` migration |
| Temporal coupling | `db!` / `client!` assigned in `onModuleInit` | Fixed — `readonly`, built in constructors |

| Finding | Status |
|---|---|
| Email request type declared twice (`SendEmailRequest`, `SendEmailJob`) | Fixed — one zod `SendEmailRequestSchema`; the service enqueues it |

## Rollout notes

- Access tokens issued before this change lack `iss`/`aud` and get 401 for up to
  `JWT_EXPIRES_IN`; clients recover through the refresh cookie.
- `0002_lowercase_emails` fails if two rows differ only by case — resolve those first.
- Set `TRUST_PROXY_HOPS` to the number of proxies in front of the API (ConfigMap sets 1).
